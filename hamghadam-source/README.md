# هم‌قدم — برنامه‌ریز کار و زندگی فارسی (نام موقت)

اپ اندروید **آفلاین و فارسی‌محور** برای ثبت سریع کارها، موعد، یادآور محلی، تقویم شمسی و عادت‌های روزانه.
این مخزن هم اسناد محصول/معماری را دارد و هم یک اپ اندروید واقعی و قابل‌ساخت (Kotlin + Jetpack Compose + Room).

> وضعیت: نسخهٔ `0.7.0` — همان برش عمودی آفلاین، به‌همراه **چند حساب محلی**، **قفل ورود با PIN**، **رمزگذاری پایگاه‌داده با SQLCipher (AES-256)**، **پشتیبان رمزگذاری‌شده با AES-GCM**، **پنل کاربری و شخصی‌سازی ظاهر**، **اعلان‌های استاندارد با دکمهٔ انجام/تعویق**، **تایمر تمرکز در نوار وضعیت**، **دو ویجت صفحهٔ اصلی**، **آیکون تازه با نمای مونوکروم** و **زبان طراحی سه‌بعدی «خمیری» با تصویر اختصاصی یک‌نور برای هر بخش، ویرایشگر کار و پنل کاربریِ برجسته** و **ممیزی کرش طبق ISO/IEC 25010 و MASVS**، **چک‌لیست (زیروظیفه) و کارهای ستاره‌دار** و **ماتریس شکاف ۱۶ حوزه / ۲۸۱ الزام** و قلم **وزیرمتن**. همگام‌سازی چنددستگاهی، ورود با سرور/OTP، پرداخت و AI **پیاده‌سازی نشده‌اند** (و به‌عمد).
> جزئیات صادقانهٔ آنچه آزموده شده و آنچه آزموده نشده در بخش [اعتبارسنجی](#اعتبارسنجی-و-محدودیتهای-فعلی) آمده است.

## قابلیت‌های این نسخه

| قابلیت | توضیح |
|---|---|
| تقویم شمسی دقیق | تبدیل دوطرفهٔ جلالی↔میلادی با الگوریتم چرخهٔ ۳۳ساله، تاریخ همه‌روزه، طول ماه و سال کبیسه |
| مناسبت‌های ۱۴۰۴ و ۱۴۰۵ (آفلاین) | `assets/events/1404.json` و `1405.json`: ۲۶ روز تعطیل رسمی در هر سال + مناسبت‌های فرهنگی و باستانی، نشانهٔ رنگی روی هر روز ماه |
| رویداد شخصی | افزودن/ویرایش/حذف با رنگ دلخواه، تکرار سالانه، یادداشت؛ انتخاب اینکه کدام تقویم‌ها فعال باشند |
| ثبت سریع فارسی | «فردا ساعت ۹ صبح جلسه با تیم #کار !!» → عنوان + تاریخ + ساعت + اهمیت + برچسب، کاملاً آفلاین و قابل توضیح |
| برچسب و فیلتر | برچسب‌های آزاد با `#`، پیشنهاد برچسب‌های قبلی، فیلتر بر اساس برچسب/لیست و جست‌وجو |
| تمرکز (پومودورو) | تایمر ۱۵/۲۵/۵۰ دقیقه، اتصال به یک کار، ثبت جلسه، هدف تمرکز روزانه و نمودار هفتگی |
| چالش روزانه | کارت بنفش «برنامهٔ تو» با سه قدم کوچک امروز (کار، تمرکز، عادت) و درصد پیشرفت؛ هیچ داده‌ای به سرور نمی‌رود |
| تمپلیت | چند تمپلیت آماده + ساخت تمپلیت از هر کار و ساخت کار امروز با یک ضربه |
| آمار | نرخ تکمیل هفته، دقیقه‌های تمرکز، زنجیرهٔ عادت‌ها و برچسب‌های پرتکرار |
| کارها | افزودن/ویرایش/انجام/حذف با واگرد، یادداشت، لیست، اهمیت، تکرار، یادآور محلی، جست‌وجو |
| موعد و ساعت | موعد تمام‌روز یا ساعت‌دار، ذخیره به‌صورت روز مطلق + دقیقه، مستقل از تغییر منطقهٔ زمانی |
| یادآور محلی | AlarmManager + اعلان با دکمهٔ «انجام شد»، زمان‌بندی مجدد پس از ری‌استارت |
| تقویم ماهانه | شبکهٔ شمسی شنبه‌محور، نقطه‌های رنگی مناسبت‌ها، انتخاب روز و افزودن کار/رویداد برای همان روز |
| عادت‌ها | ثبت روزانه روی نوار هفته، زنجیرهٔ روزهای پیوسته، جلوگیری از ثبت روز آینده |
| تقویم گوگل (اختیاری) | OAuth 2 PKCE با redirect حلقهٔ محلی + WorkManager؛ فقط یک کش محلی می‌سازد و اپ بدون آن کاملاً آفلاین کار می‌کند |
| طراحی سه‌بعدی | `Modifier.clay()`: سایهٔ محیطی + سایهٔ تماس + گرادیان حجم + خط نور لبه؛ کارت‌ها هنگام لمس فرو می‌روند. هشت تصویر سفالی اختصاصی (خانه، کارها، تقویم، تمرکز، عادت، پروفایل، تمپلیت، آمار) با حرکت شناور آرام |
| قلم وزیرمتن | چهار وزن (Regular/Medium/Bold/ExtraBold) به‌صورت OFL داخل اپ؛ متن فارسی با قلم فارسی‌محور رندر می‌شود |
| ظاهر | بوم یاسی روشن، کارت‌های سفید ۲۴dp با سایهٔ نرم، کاشی‌های پاستلی چندرنگ، نوار شناور پایین با دکمهٔ «+» مرکزی، RTL کامل، تم روشن/تیره/سیستم و ارقام فارسی قابل خاموش‌کردن |
| چند حساب محلی | هر حساب (`ProfileStore`) کارها، لیست‌ها، عادت‌ها، رویدادها، تمپلیت‌ها و جلسه‌های تمرکز خودش را دارد؛ داده‌های قدیمی به حساب اول (`id=""`) تعلق می‌گیرند و با ساخت حساب تازه از آن جدا می‌مانند. تغییر حساب با `flatMapLatest` روی همهٔ جریان‌ها اثر می‌گذارد |
| رمزگذاری پایگاه‌داده | SQLCipher 4 با AES-256؛ کلید ۲۵۶ بیتی تصادفی در EncryptedSharedPreferences (Keystore). نصب‌های قدیمی با `sqlcipher_export` مهاجرت می‌کنند و در صورت خطا دادهٔ plaintext دست‌نخورده می‌ماند |
| پشتیبان رمزگذاری‌شده | قالب `HGB1`: PBKDF2-SHA256 (۱۲۰٬۰۰۰ تکرار) + AES-256-GCM با tag احراز‌پذیر؛ پشتیبان JSON بدون رمز هم همچنان خوانده می‌شود |
| قفل ورود | PIN چهار تا هشت‌رقمی با PBKDF2-HMAC-SHA256 (۱۲۰٬۰۰۰ تکرار، نمک ۱۶ بایتی، مقایسهٔ زمان‌ثابت)، قفل خودکار فوری/۱/۵/۱۵ دقیقه و تأخیر پله‌ای تا ۶۰ ثانیه پس از تلاش‌های ناموفق؛ امکان `FLAG_SECURE` برای مخفی‌کردن پیش‌نمایش در فهرست اپ‌ها |
| پنل کاربری | تعویض/ساخت/ویرایش/حذف حساب با ایموجی و رنگ، شش رنگ تاکیدی برای کل اپ، حالت فشرده، روشن/تیره/سیستم، امنیت، و پشتیبان‌گیری هر حساب جداگانه |
| ویجت‌ها | «امروز» ۴×۲ (تاریخ شمسی، شمار کارهای باز، سه کار بعدی، دکمهٔ افزودن) و «تمرکز» ۲×۲ (دقیقه‌های امروز در برابر هدف، شروع ۲۵ دقیقه)؛ هر دو با `updatePeriodMillis` نیم‌ساعت و بازآوری فوری پس از تغییر داده |
| اعلان‌های استاندارد | چهار کانال جدا (یادآور HIGH، تمرکز LOW، خلاصه DEFAULT، عادت DEFAULT)، گروه‌بندی یادآورها با summary، دکمه‌های «انجام شد» و «۱۰ دقیقه بعد»، `VISIBILITY_PRIVATE` و درخواست مجوز `POST_NOTIFICATIONS` فقط یک‌بار |
| تایمر تمرکز پس‌زمینه | `FocusService` با `foregroundServiceType="specialUse"` و کانال بی‌صدا؛ شمارش معکوس با خاموش‌بودن صفحه هم ادامه می‌یابد |
| پشتیبان نسخهٔ ۲ | خروجی/بازیابی JSON شامل کارها، برچسب‌ها، لیست‌ها، عادت‌ها، رویدادهای شخصی، تمپلیت‌ها و جلسه‌های تمرکز؛ فایل نسخهٔ ۱ هم خوانده می‌شود |

هیچ داده‌ای پیش‌فرض به شبکه نمی‌رود. تنها مسیر شبکه‌ای، اتصال **اختیاری** تقویم گوگل است که کاربر خودش Client ID را وارد و اتصال را فعال می‌کند؛ در همهٔ حالت‌ها دادهٔ محلی منبع حقیقت است.

## ساختار مخزن

```text
hamghadam-source/
├─ apps/android/                     اپ اندروید (Kotlin، Compose، Room)
│  └─ app/src/main/
│     ├─ java/ir/hamghadam/app/
│     │  ├─ domain/                  منطق خالص و تست‌پذیر: تقویم، پارسر فارسی، تکرار، برچسب، تمرکز، آمار، رویداد
│     │  ├─ data/                    Room (کار/لیست/عادت/رویداد/تمپلیت/تمرکز/کش گوگل)، مخزن، تنظیمات، کدک پشتیبان
│     │  ├─ google/                  OAuth PKCE + حلقهٔ محلی + WorkManager (کاملاً اختیاری)
│     │  ├─ notify/                  زمان‌بندی یادآور، گیرندهٔ اعلان، بازسازی پس از ری‌استارت
│     │  └─ ui/                      Compose: خانه، کارها، تقویم، تمرکز، بیشتر، آمار، تمپلیت، تنظیمات
│     └─ assets/events/              مناسبت‌های ۱۴۰۴ و ۱۴۰۵ (JSON نسخه‌دار)
├─ docs/                             اسناد محصول، معماری، نقشهٔ صفحات و یادداشت پیاده‌سازی
├─ ci/                               workflow آمادهٔ ساخت APK + راهنما
├─ tools/generate-events.py          بازتولید فایل‌های مناسبت‌ها از فهرست منابع
├─ services/api/                    سرورلس اختیاری (Vercel، Node، بدون وابستگی): health + پیشنهاد ابزارهای دستیار، ۲۱ تست
├─ services/supabase/migrations/    اسکیمای Postgres + RLS برای سرور اختیاری (اجرا‌نشده)
└─ services/api/openapi.yaml        قرارداد OpenAPI همان API
```

معماری اپ: تک‌Activity + Compose، `AppViewModel` با `StateFlow`، Room به‌عنوان منبع حقیقت محلی، تزریق دستی وابستگی در `AppContainer`. لایهٔ `domain` هیچ وابستگی اندرویدی ندارد و روی JVM تست می‌شود.

## اعتبارسنجی و محدودیت‌های فعلی

**آنچه واقعاً اجرا و بررسی شده است:**

- **بیلد واقعی Gradle/Android روی GitHub Actions سبز است**: `:app:testDebugUnitTest` و `:app:assembleDebug` هر دو موفق و APK دیباگ روی release غلتان `latest-debug` منتشر می‌شود (حدود ۳ دقیقه برای هر اجرا).
- **۱۴۷ تست JVM در ۲۱ کلاس** با موفقیت اجرا می‌شود؛ از جمله تست مناسبت‌های واقعی ۱۴۰۴/۱۴۰۵، تمرکز، چالش روزانه، قالب گوگل کلندر و پشتیبان نسخهٔ ۲ (`JalaliDate`, `PersianText`, `PersianCalendar`, `QuickAddParser`, `RepeatRule`, `TaskQuery`, `Tags`, `BackupCodec`, `BackupV2`, `EventCalendar`, `FocusStats`, `DailyChallenge`, `GoogleOAuth`, `GoogleCalendarApi`, `ProfileCodec`, `PinSecurity`, `ProfileScope`, `BackupCipher`, `DatabaseCrypto`، و تست‌های رابط کاربری `LockScreenTest`/`AccessibilityTest` با Robolectric).
- تبدیل تاریخ جلالی با پیاده‌سازی مرجع `jdatetime` برای **هر ۱۰۹٬۹۳۸ روز بین ۱۸۵۰ تا ۲۱۵۰** مقایسه شد: صفر اختلاف، صفر خطای رفت‌وبرگشت.
- کل کد اپ (شامل Compose، Room، AlarmManager و ViewModel) در این محیط با یک «آینهٔ stub» از APIهای اندروید/Compose از نظر **نوع و امضا** بررسی شد؛ خطای نحوی/امضایی باقی نمانده است.

**آنچه هنوز واقعاً آزموده نشده است:**

- ساخت کامل Gradle/Android (AAPT2، kapt/Room، R8، نصب روی دستگاه) در این محیط انجام نشده، چون Android SDK و مخازن Maven قابل دسترسی نبودند. اولین بیلد واقعی روی CI یا Android Studio انجام می‌شود؛ احتمال خطاهای جزئی در تنظیمات Gradle یا APIهای کمتر‌استفاده‌شدهٔ Compose وجود دارد.
- تست‌های رابط کاربری با **Robolectric** روی JVM اجرا می‌شوند (کلیدpad، هدف لمسی ۴۸dp، برچسب صفحه‌خوان، `fontScale = 2.0`)، اما این جانشین آزمون روی دستگاه نیست: هیچ اجرای واقعی با **TalkBack**، لانچر واقعی یا دستگاه فیزیکی انجام نشده است.
- مسیر مهاجرت پایگاه‌داده از plaintext به رمزشده کامپایل و از نظر منطقی بررسی شده، ولی **ارتقای واقعی ۰.۴.۰ → ۰.۵.۰ روی گوشی اجرا نشده است**.
- ویجت‌ها، اعلان‌ها و سرویس پیش‌زمینه در بیلد کامپایل و تست می‌شوند، اما **روی لانچر واقعی و با مجوزهای واقعی اندروید ۱۳/۱۴ اجرا نشده‌اند**.
- رمزنگاری پایگاه‌داده و پشتیبان انجام شد؛ آنچه نمانده: بیومتریک، پشتیبان خودکار زمان‌بندی‌شده و `VACUUM` پس از حذف حساب.
- همگام‌سازی سرور، احراز هویت، پرداخت، AI و OCR/صوت پیاده‌سازی نشده‌اند.

## گام‌های بعدی پیشنهادی

1. اجرای workflow و رفع خطاهای احتمالی بیلد؛ سپس افزودن تست instrumented برای ثبت سریع و یادآور.
2. استقرار سرور اختیاری روی پروژهٔ آزمایشی Supabase/Vercel و آزمون RLS، سپس اتصال صفحهٔ «دستیار» در اپ (اسکلت در `docs/12`).
3. لایهٔ همگام‌سازی: صف outbox پایدار + قرارداد `POST /v1/sync/operations` (اسکلت در `docs/02` طراحی شده).
4. فایل مناسبت‌های ۱۴۰۶ (همان قالب JSON)، جست‌وجوی سراسری و زیرکار، و آزمون ویجت‌ها روی لانچرهای مختلف.
5. آماده‌سازی انتشار: امضای AAB، سیاست حریم خصوصی، سنجش crash-free، دسترس‌پذیری (TalkBack/کنتراست).
