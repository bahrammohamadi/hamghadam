## گرفتن APK بدون نصب ابزارهای Android روی رایانه
در `.github/workflows/android-apk.yml` یک workflow ساخت ابری اضافه شده است. اگر حساب GitHub دارید، کل مخزن را در یک repository بارگذاری کنید (یا این پروژه را به GitHub push کنید)، سپس تب **Actions → Build Android APK → Run workflow** را اجرا کنید. GitHub در ماشین ابری JDK/SDK/Gradle را آماده می‌کند و فایل `app-debug.apk` را به‌صورت Artifact با نام `hamghadam-debug-apk` می‌سازد؛ آن را از اجرای موفق workflow دانلود کنید. نصب APK آزمایشی روی گوشی ممکن است نیازمند اجازهٔ نصب از منبع مورد اعتماد باشد. این APK debug است، نه نسخهٔ انتشار امضاشده.

این مسیر به حساب GitHub و دسترسی اینترنت نیاز دارد. برای ساخت محلی: Android Studio، JDK 17 و Android SDK لازم است. در این محیط ساخت APK انجام نشده و workflow نیز هنوز در GitHub اجرا/تأیید نشده است.

## پیاده‌سازی فعلی
اپ اندروید شامل ذخیره‌سازی محلی Room و عملیات واقعی افزودن/انجام/حذف وظیفه است؛ اطلاعات در دیتابیس محلی باقی می‌ماند. هنوز موعد/تکرار/یادآور، موتور تاریخ شمسی، صف outbox، همگام‌سازی سرور، احراز هویت و همکاری پیاده‌سازی نشده‌اند. صفحهٔ فعلی یک برش عمودی محلی است، نه نسخهٔ تجاری کامل.

## وضعیت صداقت محصول
هیچ اتصال واقعی به OTP، پیامک، پرداخت، AI، تقویم دستگاه یا سرور عملیاتی وجود ندارد. APK/AAB امضاشده، پنل مدیریت و استقرار تولیدی ساخته نشده‌اند. در محیط حاضر `gradle`/Android SDK در PATH در دسترس نبود، بنابراین build و تست Android اجرا نشده است؛ برای ارزیابی، Android Studio، JDK 17 و Android SDK لازم است. جزئیات در اسناد آمده است.
